# Snake_game
# 🐍 Dot Matrix Snake Game  A modern Snake Game built with HTML5, CSS3, and Vanilla JavaScript.  **Features:** - Dot Matrix design with neon effects. - Growing snake mechanics. - Infinite wall wrapping. - Keyboard and mobile touch controls. - Responsive design. - Live score, pause and restart.  **Tech Stack:** HTML5 | CSS3 | JavaScript | Canvas API
